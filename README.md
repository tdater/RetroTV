# RetroTV

An Android TV app for playing retro games without installing emulators. It's a streamlined TV browser built around in-browser emulation sites.

- 16 built-in game sites (RetroGames.cc, PlayClassic, ClassicReload, Emulator Gamer, Retro Games Nexus, Internet Arcade, OldGames, Afterplay, Rec0deD:88, and more). You can also add your own.
- Remote-friendly pointer, D-pad-keys mode, and full controller support (Gamepad API in every frame, or keyboard mapping).
- Windowed, full screen and "Focus game" modes.
- Ad, pop-up and redirect blocking that leaves game files and navigation alone. It can be switched off per site.
- Desktop or mobile/TV view per site.
- Install any built-in site as its own TV app with its own banner and sandboxed sign-ins.
- Userscript manager with one-click Greasy Fork search.
- Emulator APK downloads from official sources, game sources, and a direct-link downloader that installs APKs.
- Themes, card sizes, overscan margin, pointer speed and size, button remapping, backup and restore.

Built on GitHub Actions; the `app-debug` artifact contains the APK.
